# Metronomicon for Disting NT — manual (v1.9)

Accented metronome for the Expert Sleepers Disting NT that follows an external MIDI or
CV clock (e.g. Squarp Hermod+) or its own internal tempo (with tap tempo), plus two extra
layers that run alongside it: a **polyrhythm generator** (X pulses over Y quarter notes)
and a **rhythm pattern generator** (59 patterns in 9 groups). Every layer has its own
audio and CV outputs.

```
src/metronome_engine.h   timing + sound engine (platform-independent, header-only)
src/patterns.h           pattern table (generated by tools/gen_patterns.py)
src/metronome.cpp        Disting NT plugin glue: parameters, buses, MIDI, display
tests/test_engine.cpp    host test suite (228 checks)
tools/gen_patterns.py    readable pattern list -> src/patterns.h
build.ps1 / Makefile     Windows / macOS-Linux builds
```

## Build

**Match the API to your firmware.** Firmware 1.18 = API v13 = tag `v1.18.0`:
https://github.com/expertsleepersltd/distingNT_API/archive/refs/tags/v1.18.0.zip

**Windows:** `.\build.ps1` (Arm GNU Toolchain `arm-none-eabi` on PATH, API unzipped next
to this folder). **macOS / Linux:** `make NT_API=path/to/distingNT_API-1.18.0`; `make test`.

Copy `plugins/metronomicon.o` to `/programs/plug-ins/`. The plugins page should show **v13**.

> Presets from v1_2 shift: parameters were added (internal clock, tap, pattern group,
> swing, accent out). Re-check settings once after loading an old preset.

### Internal clock, transport and tap tempo

- Clock source **Internal** runs from *Internal BPM*. Start and stop it with the **left
  encoder** (on the Metronomicon display), the **Play** parameter (mappable to a button or
  MIDI note), or the CV transport input: RUN = gate high plays, TOGGLE = each trigger
  plays/stops, RESET = restart at bar 1 while playing, NONE = ignore. Every start is bar 1.
  Metronomicon is always **stopped after loading** a preset or powering up.
- **Tap**: press the **right encoder** while the metronome's display is showing, or in the
  parameter menu turn the *Tap* parameter **right** — every step is a tap, so just keep
  turning (left does nothing). *Tap* can also be mapped to a gate, button or MIDI note (one
  tap per press), or send triggers to *Tap input*. Internal clock only. Two or more taps (up to the last five, gaps under
  2.5 s) set the tempo immediately and write it into *Internal BPM*, so it's saved with the
  preset.
- Internal tempo uses a double-precision accumulator: no drift over hours.

### Count-in

*Count-in* (Off / 1–4 bars, Internal clock only) plays that many bars of the current time
signature before bar 1, on its own higher "tick" sound, accenting each bar's first beat. It's
heard even when *Metro audio* is off. During the count nothing else runs: no polyrhythm or
pattern, no CV clock/reset/triggers, no MIDI clock or notes, unless:

- *MIDI count out* = On (Output page, needs MIDI out) — the count is also sent as notes
  (downbeat / beat notes).
- *Count-in clock* = **Run** — MIDI clock and the base CV clock run through the count so a
  receiver can lock to the tempo first; MIDI Start is still sent exactly on bar 1. **Wait**
  (default) holds the clock until bar 1.

The screen shows `IN 2`, `IN 1` (bars left) and highlights the count beat. Stopping during the
count cancels it.

### Recording (arming samplers and loopers)

| Parameter | |
|---|---|
| Rec arm | arm the next take (switches itself off when the take ends) |
| Rec length | Manual, or 1 / 2 / 4 / 8 / 16 bars |
| Rec out | CV output; *Rec out mode* Trigger = pulse at start and at end (toggle-style loopers/samplers), Gate = high for the take |
| Rec MIDI note | note sent at start and end (Trigger) or held for the take (Gate); Off by default |

Takes always start and end **exactly on a bar line**:

- **Armed while stopped:** recording starts on bar 1 (after the count-in, if any).
- **Armed while playing:** punch-in on the next bar line.
- **Manual length:** the take runs until you disarm (ends on the next bar line, playback
  continues) or press stop (playback and the take end together on the next bar line).
- **Fixed length:** the take ends after exactly that many bars; playback continues so you hear
  the loop come back in time.
- Stop is only quantized while recording; otherwise it's immediate.

Typical setups:

- **Device with no tempo (sampler, looper, field recorder):** Internal clock, Count-in 1 bar,
  Rec out → its record/trigger input (Trigger or Gate to suit), Rec length Manual or a loop
  length. Arm, press play: *1 2 3 4*, recording starts on bar 1 and ends on a bar line.
- **Device with tempo (drum machine, sequencer, DAW):** add *MIDI clock out* (and/or patch
  *Run out* + *Base clock out*) so it plays in sync; set *Count-in clock* to Run if it needs
  to lock to the tempo before bar 1.

### Sync outputs (when Metronomicon is the master)

- **MIDI clock out** — 24 PPQN clock to *MIDI out dest*, Start on bar 1, Stop on stop
  (a RESET while playing sends Stop then Start). Not sent when following MIDI clock.
  Turning it on also turns on *MIDI out*, setting *MIDI layers* to None if MIDI out was off,
  so you get clock without drum notes. *Rec MIDI note* does the same.
- **Run out** — gate high from bar 1 until stop.
- These work with the CV clock as well: Metronomicon re-transmits the CV clock as MIDI clock.

### Patterns

Pick a **group**, then a pattern within it. Changing the group jumps to its first pattern.
Notation in `tools/gen_patterns.py`: `X` accent, `x` hit, `g` ghost (40 % level), `.` rest.

| Group | Patterns |
|---|---|
| Afro-Cuban/African | Tresillo, Son clave 3-2, Son clave 2-3, Rumba clave 3-2, Rumba clave 2-3, Cinquillo, Habanera, Cascara, Std bell (bembe), Bell 5-stroke, 6/8 short bell |
| Odd meter | 5/8 2+3, 5/8 3+2, 7/8 2+2+3, 7/8 2+3+2, 7/8 3+2+2, 9/8 3+3+3, 9/8 2+2+2+3, 9/8 2+2+3+2, 9/8 2+3+2+2, 11/8 3+3+3+2, 11/8 2+2+3+2+2, 11/8 3+2+3+3 |
| Swing/shuffle | 8th swing, 16th swing, Triplet shuffle, Half-time shuffle |
| Jazz/practice | 2 and 4, 8th offbeats, 16th offbeats (e), Displaced (a), Charleston, Jazz ride, Jazz ride + 2/4, Half-time backbeat |
| Indian tala | Teentaal 16, Jhaptal 10, Rupak 7, Dadra 6, Keherwa 8 |
| Middle Eastern | Maqsum, Baladi, Saidi, Malfuf, Samai thaqil 10/8, Aksak 9/8 |
| Brazilian | Bossa nova, Samba, Partido alto, Baiao, Maracatu |
| Caribbean | Dembow, One drop, Steppers |
| Funk/electronic | Syncopated 16ths, Funk backbeat, Half-time groove, Four on the floor, Accent cycle |

- **Accents** use the strong sound and fire **Pat accent out**; every hit (ghosts
  included) fires **Pattern trig out**.
- **Swing** applies to the swing patterns (8th / 16th swing): 50 % straight, 66 % triplet,
  75 % dotted. Other patterns ignore it (the parameter is greyed out).
- Odd-meter patterns accent each group start, strongest at the cycle start. Tala: sam =
  accent, claps = hits, waves (khali) = rests, other matras = ghosts. Middle Eastern: D =
  accent, T = hit. Several Brazilian/Caribbean entries are reduced guide patterns, as the
  source doc notes. Bembé and the 12-pulse "6/8 long bell" are the same timeline, so only
  one is included; Gahu is omitted until a specific documented bell variation is chosen.

### Pattern CV and dynamics

| Output | Fires on |
|---|---|
| Pattern trig out | every hit, or every non-ghost hit with *Pat trig mode = No ghosts* |
| Pat accent out | accented hits |
| Pat ghost out | ghost hits |
| Pat velocity out | stepped CV, set at each hit and held: **5 V** accent, **3.5 V** hit, **1.5 V** ghost |

The velocity CV changes on the hit's sample, never after its trigger, so it can feed a VCA,
a drum module's level/decay input or a sample & hold clocked by the trigger.

### MIDI drum output

*MIDI out* is the master switch for all MIDI output. With it on, every click is also sent as a MIDI note to the chosen destination and
channel (default 10, the GM drum channel), so the metronome and its layers can play a drum
machine or sampler. Defaults use GM notes: downbeat 76 (hi wood block), beat 77 (low wood
block), subdivision 42 (closed hat), poly 56 (cowbell), pattern 75 (claves).
*Poly accent note* (first pulse of each X:Y cycle, when Poly accent is on) and *Pat ghost
note* default to the poly and pattern notes; give them their own notes to split e.g. a 5:4
into ONE on one sound and two–five on another, or send ghosts to a quieter kit piece.

- Velocity follows the voice levels: downbeat 127, beat 83, subdivision 32 at default
  levels; accents (poly cycle start, pattern accents) are boosted to 127; ghosts ≈ 36.
- Note-offs follow 15 ms later. A repeated note ends the previous one first.
- *MIDI layers* chooses which layers send notes; **None** sends no notes (clock and rec note only). MIDI ignores the audio switches and Mute
  all, so you can turn the NT's own clicks off and drive only the external kit.
- Notes are sent with the audio block containing the click (sub-millisecond).

### Click sound

*Classic* is the woody, ringing set. *Soft* is a lower, short, dry set (more thump and
less ring) for every layer; the timing is identical.

## How timing works

Position is counted at 24 PPQN. Every clock event (MIDI 0xF8, CV edge, or internal tick)
anchors the timeline; metronome subdivisions, polyrhythm pulses at fractional positions and
(swung) pattern steps inside the next interval are scheduled sample-accurately from the
measured clock period. When the next clock event arrives, anything pending fires and the
timeline re-anchors: no drift, and nothing runs on a stale tempo.

Layers keep independent cycles from the session origin and never reset each other; ratio,
pattern and poly clock changes land on the next cycle boundary, time signature at the next
bar. A layer's clock/trigger output trails its reset by 1 ms when the reset output is used.
Turning audio off never stops CV.

### CPU

Each audio block is processed in two passes. Pass 1 walks the timeline — scanning inputs
per sample only when a CV clock/transport/tap input must be watched, otherwise jumping
straight from event to event — and records click and trigger events with their sample
offsets. Pass 2 renders only the voices that are actually sounding (tight two-resonator
loops), and writes CV outputs as constant runs between events. On the host this is 4–7×
faster than v1_2 for the same work (metronome only: 40 → 6 ns/sample; all layers + every
CV output: 58 → 16 ns/sample). Click tails were also shortened to −56 dB.

Footprint: ~5.5 KB SRAM per instance, ~18 KB code.

## Hermod+ setup

**CV:** CLOCK OUT (24 PPQN) → NT input 1, RESET OUT → NT input 2. Set the Hermod output to
RESET to use the new default, or set *CV transport* to RUN if it's configured as RUN.

**MIDI:** Hermod MIDI out → NT MIDI in, sending clock + transport. Source = MIDI.
